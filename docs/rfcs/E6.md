# RFC E6: wiring Ask, and four small contract requests

Owner: E6 (agent jobs & Ask). For the integrator (E1) and the owners named below. Nothing here blocks the build:
`createAssistantExecutor(deps?)` compiles and runs without arguments (Ask then answers "Cortex can't find Claude
Code", every other call is inert), so the container keeps working until this lands.

## 1. E1: give the executor its dependencies (`src/plugin/container.ts`)

`createAssistantExecutor` now takes `AssistantDeps` (exported from `src/plugin/aiExecutor.ts`). The notes writer is
not a dependency of the plugin side: machine notes are written by the runner (the jobs that `refresh` queues) and
left-out notes are placed by `corrections`. Hoist the record reader into a const, then:

```ts
const records = createRecordReader({ /* unchanged */ });
...
assistant: createAssistantExecutor({
  runner: bg.runner,
  ledger: ledgerStore,                 // LedgerStore.append("receipts", …)
  reader: bg.ledger,                   // LedgerService.changes / askHistory / invalidate
  corrections,
  index,                               // index.index.peek(), meta(), ordinalOf()
  worker,
  records,                             // entryText for correct_entry and Ask history
  settings: bg.settings,
  shared: bg.shared,                   // receipts slice for the console; activity slice for the cap
  leaves: { store: (viewId) => leaves.get(viewId)?.store },
  sandbox: () => sandbox.peek(),
  log: bg.log.child("assistant"),
}),
```

The `AssistantExecutor` interface grew compatibly: `undo(id, { both? })`, `undoPreview(id)` (a later change that touched
the same item, for "Undo both"), `changes({ filter })` returns `ReceiptView[]`, `history()` returns
`AskExchangeView[]` (with the stored entry ids), `AskEvent` progress carries `askId` (for Stop), and error codes
`paused`, `offline`, `limit` were added (their texts are existing keys `agents.paused`, `agents.offline`,
`agents.limit`).

Keymap (E11): "Undo or redo the last Cortex change" should call `services.assistant.redo()` on Ctrl Shift Z.

## 2. E11: import the stylesheet

`src/styles/ask.css` holds every rule for the console, change cards, slash list and Change history (all `.cx-` and
under existing tokens). Add after `pages.css` in `styles.css`:

```css
@import "./src/styles/ask.css";
```

## 3. Architect: `AiAskResult` already carries two fields at runtime

`runAnswer` returns the model's reason per action and the raw reply when it could not be used. The plugin reads them
defensively today; please add them to `src/shared/protocol/runner.ts`:

```ts
export interface AiAskResult {
  // …existing fields…
  /** The model's reason per returned action (aligned with `actions`; null when none). */
  reasons?: (string | null)[];
  /** The raw model reply when it could not be used at all ("Show the raw reply"); `reply` is then empty. */
  raw?: string;
}
```

## 4. E12: open the console earlier

The command line opens the console on Enter (and on switching to Ask). The console sends the text itself (it listens
for Enter on `.cx-command-input`) and completes slash commands on Tab. For the slash menu to show *while typing*,
`CommandLine` should set `command.consoleOpen` as soon as Ask mode has focus or the text starts with `/`.

## 5. Runner (E5): discard filing checks

Undo of `propose_filing` removes jobs that have not run (`agents.dequeue`). Checks the job already wrote stay in
Agents › Checks, where the person can skip them. A runner command that marks cards of a run as dismissed
(`review.discard { runId }`) would make Undo complete; until then the change card says "Cancel", not "Undo change".
