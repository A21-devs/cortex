# RFC E3: importers I, Sources service, Add sources

Owner: E3. Each item is a request to the architect or to the named owner. E3 uses a local adapter meanwhile, so nothing here blocks the build.

## 1. Wire the two services with their dependencies (plugin/container.ts, E1)

What: `createSourcesService(deps?)` and `createNewEntryService(deps?)` now take their dependencies. Called with none (as `container.ts` does today) they still compile; Sources calls then throw `E_INTERNAL` ("Sources is not connected to the vault") and New entry only keeps drafts in memory.

Why: both need the vault, the cache, the runner, settings and corrections; the container owns them.

```ts
// container.ts, inside createServices, after `corrections`, `index` and `sandbox` exist
sources: createSourcesService({
  app: bg.app, vaultRoot: bg.vaultRoot, cacheDir: bg.cacheDir, log: bg.log.child("sources"),
  settings: bg.settings, runner: bg.runner, corrections,
  index: () => index.index.peek(),
  importing: () => activity.peek().importing !== undefined,   // activity: the ActivityState signal
  sandbox: () => sandbox.peek(),
  save: (req) => saveFile(req, saveDeps),   // plugin/saveFile.ts with the notice + dialog deps
}),
newEntry: createNewEntryService({
  vaultRoot: bg.vaultRoot, cacheDir: bg.cacheDir, log: bg.log.child("new-entry"),
  runner: bg.runner, sandbox: () => sandbox.peek(),
}),
```

## 2. `import.estimate` and the importer wrapper (runner/commands.ts, E5)

What: `import.estimate` should be `estimateSources(args.sources, ctx)` from `importers/registry.ts`; it lists directories and file sizes only (plus the first 2 KB of each vault note to count `status: reference`) and returns the `EstimateResult` (constants `TOKENS_PER_CONVERSATION = 2500`, `TOKENS_PER_NOTE = 1100`, days = ceil(tokens / dailyTokenCap)). Run imports through `createImporters()`: its `run` wrappers also keep `<cache>/state/not-local.json` (files found only as OneDrive placeholders), which Sources › Fetch now reads.

Why: SAFE-11 (counts before anything is imported or sent) and the "12 files are in OneDrive but not on this computer yet" row.

## 3. Contract additions on `SourcesService` (plugin/services.ts, architect)

```ts
// importNow should report what happened (the Add sources done line needs counts, secrets and skips)
importNow(source: SourceSelector): Promise<ImportResult>;
// "Ask per file" in Add sources (today reached through SourcesServiceExt in ui/modals/AddSourcesModal.ts)
listFolderFiles(root: string, extensions: readonly string[]): Promise<string[]>;
saveFolderSpeakers(folderId: string, files: Record<string, "you" | "other">): Promise<void>;
```

Local adapter: the dialog feature-detects the two folder calls (it hides "Ask per file" without them) and derives its done line from the inspect preview.

## 4. Confirming "Changed on disk · import the new version?" (runner ImportArgs, E5)

What: `ImportArgs.importChanged?: boolean | string[]`; the runner sets `ctx.options = { importChanged }` for the `raw` importer (`RawSelectorOptions`).

Local adapter: `SourcesService.importNow({kind:"raw"})` ("Import again") writes `<cache>/state/import-changed.json` (`{v:1, all:true}`) and `importers/rawDocs.ts` reads and consumes it after a complete pass. A per-file confirmation can use `{v:1, paths:[…]}` the same way.

## 5. Exclusion targets (plugin/corrections.ts, E6 / indexBuilder.ts, E2)

What: `Remove source…` calls `corrections.exclude(id, "source", "sources")` with the Sources row id: `claude-code`, `claude-ai`, `chatgpt`, `gemini`, `written`, `vault`, `raw`, `folder:<id>`. The importers test the same ids (`ExclusionQuery.sourceId`, via `sourceIdOf()` in `importers/common.ts`), so the index builder should map an entry to its row id with `sourceIdOf(entry)` when applying a source-scope exclusion (`obsidian` entries are `vault`; `files` entries are `raw` or `folder:<id>`).

## 6. Copy and styles (ui/copy.ts, styles/, E11)

Strings the dialog needs that the catalogue does not have are local constants in `AddSourcesModal.ts` (`LOCAL`): "Importing…", the done lines, "Cortex couldn't tell which service this came from…", "All mine", "All another person's", "Leave out", "Couldn't save this setting. Try again.". Row layout uses inline styles on `.cx-source-row`, `.cx-source-tile`, `.cx-source-panel`; E11 may move them into `styles/shell.css` (classes are already set).
