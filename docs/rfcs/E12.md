# RFC E12 — contract requests from pages, readers and Find

Nothing here blocks E12: each item has a local adapter in place today. They are listed so the architect can
decide whether to widen a contract.

## 1. Read rows: a snippet per row (`shared/protocol/worker.ts`)

CORTEX-UX §5.18 gives every Read row one snippet line. `StatsResult` `kind: "read"` rows carry only
`{ ordinal, count, youShare }`, so the row shows the message count (or the area) instead of text.

```ts
| { kind: "read"; total: number; rows: { ordinal: number; count: number; youShare: number; snippet?: string }[]; folders: { path: string; count: number; depth: number }[] }
```

`snippet` would be the first 120 characters of the entry or conversation opening, taken from the immutable
segment text (never machine text).

## 2. Rhythm grid cells as tokens (`worker/indexOps.ts` group tokens)

`time.rhythmToken` ("Tue 09–10") needs a query token for one weekday x hour cell. Group tokens read
`dimValue(index, o, dim)`, which has no `weekday` or `hour` dimension although `DateGrain` lists both. Please
make `dimValue` answer `weekday` ("0".."6", week-start independent, Monday = "0") and `hour` ("00".."23"), then
the grid cells can add `{ kind: "group", dim: "weekday", value }` plus `{ dim: "hour", value }`. Until then the
cells only carry their tooltip.

## 3. Access log: what a model read (`plugin/services.ts` `LedgerService`)

Agents › Access log should let a click trace what a model read (`agents.traceRead`). The aggregates in
`AccessRow` carry no ids.

```ts
accessIds(model: string, route: string): Promise<{ entries: string[]; notes: string[] }>;
```

The page would add one `{ kind: "set", ids }` token. Until then rows are read-only.

## 4. Ask from the command line (`ui/command/CommandLine.tsx` ↔ E6)

In Ask mode Enter keeps the question in `ui.command.text` and sets `ui.command.consoleOpen`. The Ask console
(E6) is expected to send `ui.command.text` through `AssistantExecutor.ask()` when it opens with text, then clear
it. If E6 prefers an explicit signal, add `ask: { viewId: string; text: string }` to `CortexEvents`
(`state/events.ts`) and the command line will emit it instead.
