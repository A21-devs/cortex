# E9 (Charts) — requests for wiring outside E9's files

E9 works with local adapters meanwhile; each item says what the adapter is, so the swap is local.

## 1. A `stage:chart` event from the render controller (drops a second arrangement call)

**Why.** The controller holds each chart `ArrangementResult` but only publishes `stage:arrangement` (sparse, flat). The overlay model's marks, `readings`, `categories` (Top N, Folders checklist, Combine, CSV) never reach the UI. Adapter: `ChartFeed` (stage/ChartOverlay.tsx) asks the worker for the same arrangement under its own latest-wins key `‹viewId›#chart`, debounced 120 ms, so the renderer's call is never superseded. It costs one extra layout per chart change (tens of ms on the sample record).

**Proposed** (`StageEvents`, `ui/context.ts`; emitted in `controller.arrange()` next to `stage:arrangement`):

```ts
"stage:chart": { viewId: string; spec: ChartSpec; result: ArrangementResult };
```

The worker `ViewState` map gets a few empty entries for `‹viewId›#chart` and `‹viewId›#csv`; `dropView(viewId)` could also drop keys that start with `viewId + "#"`.

## 2. Save image should draw resolved label text

`render/exportPicture.ts` draws `OverlayItem.text` as the worker sent it. Labels that name a copy key (`ref.copy`: Today, the map-sources chip, You / Assistant) arrive with empty or numeric text, and category labels use the worker's fallback names (No area, enum ids). The screen overlay resolves them with `overlayLabelText(text, parseRef(item.key))` (stage/ChartOverlay.tsx). Request: E10 takes a `labelText?: (item) => string` dependency from the controller, which the shell passes as that function; or the architect moves `parseRef`, `categoryName` and `overlayLabelText` into `src/shared/`.

## 3. The key bar's pickers should drag

Dimension chips on the Chart page drag with the type `application/x-cortex-dim` (`DIM_MIME`) and the three stage drop zones (Horizontal, Vertical, Colour) appear on any `dragstart` carrying it. Request (E11): `KeyBar` pickers set the same type in their `dragstart` (`e.dataTransfer.setData(DIM_MIME, dim)`).

## 4. Commands that Chart-page buttons rely on

`save-image` and `copy-data-csv` are registered at feature `pinView` (P2, `plugin/commands.ts`), but the Chart page (P1) and More menu need them. The page emits the leaf `command` event directly, so it works regardless; the palette entries still wait for P2. Request: register both at `chartPage`.

## 5. Phase gates E9 follows

`featureOn("highlightTokens")` (P2) makes axis and band labels clickable tokens; `featureOn("combineValues")` (P2) enables right-click "Combine with…"; `featureOn("pinView")` (P2) shows P2 charts in the gallery and the Pin view button. Mark hover and click-to-trace follow `chartShape` (P1). Nothing else is gated.
