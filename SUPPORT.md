# Getting help with Cortex

Cortex has one maintainer, so please pick the right place. It gets you an answer sooner.

| You want to | Go to |
|---|---|
| Learn how to install it, add sources, set up the agents, or what gets sent where | The [user guide](https://github.com/A21-devs/cortex/wiki) |
| Ask a question, or get help when something is confusing | [Discussions › Q&A](https://github.com/A21-devs/cortex/discussions/categories/q-a) |
| Suggest an idea or vote on one | [Discussions › Ideas](https://github.com/A21-devs/cortex/discussions/categories/ideas) |
| Report something that is broken | [A bug report](https://github.com/A21-devs/cortex/issues/new?template=bug_report.yml) (the form asks for the version, Windows version and steps) |
| Report a security problem | Privately, see [SECURITY.md](SECURITY.md). Not in an issue |

See what's planned on the [roadmap](https://github.com/A21-devs/cortex/wiki/Roadmap).

## What to include

- Cortex version (Settings › Community plugins, or `manifest.json`) and whether it's the plugin or Cortex Desktop
- Windows version and Obsidian version
- What you did, what you expected, and what happened instead
- Console lines if there are any (Ctrl+Shift+I in Obsidian)

Leave out note titles, file paths, chat text and anything else personal. If a screenshot would show your notes, try to reproduce it with the sample record instead (More menu › Sample record).

## How fast you'll hear back

Usually within a few days. This is a one-person project, so it can take longer around busy weeks. Bug reports with clear steps get looked at first.
